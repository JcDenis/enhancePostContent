Filtre
Choisissez dans la liste le filtre à régler. Chaque filtre ajoute une fonction aux mots de vos billets : abréviation, citation, lien, mot-clé, remplacement, etc.
Réglages
Choisissez les pages et les contenus où le filtre agit, la façon de trouver les mots, le nombre de remplacements, le style CSS et les balises HTML à ignorer.
Enregistrements
Liste des mots du filtre : la clé est le mot à trouver, la valeur est son explication, son lien ou son remplacement. Sélectionnez des enregistrements pour les supprimer.
Nouvel enregistrement
Ajoutez un mot au filtre, avec sa clé et sa valeur.
Paramètres du blog
Le plugin doit être activé dans les paramètres du blog, dans les paramètres des plugins, pour filtrer les contenus et afficher son widget.
